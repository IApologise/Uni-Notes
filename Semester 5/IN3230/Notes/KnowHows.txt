--- Technologies ---

    Memory Related Hardware
1. Cache : Data directly and closely connected to the CPU for very fast access, limited in size.
2.   RAM : Stands for Random Access Memory, it is slower yet larger than Cache. Data is fetched from it and loaded
           into Cache once a relevant operation is performed on a given process.
3.   HDD : Stands for Hard Disk Drive, both Cache & RAM lose information once electricity is out, HDD's doesn't.
           The price is much slower speed but a much larger capacity & reliability.
4.   SSD : Stands for Solid State Drive, its functionality is same as that of an HDD, but it is simply better.
Note how the largest trade-off between memory storages is less Distance equals less Capacity but more Speed.

    Compute Related Hardware
1. CPU : Stands for Central Processing Unit, it operates on data sequentially using many different operations.
2. GPU : Stands for Graphics Processing Unit, it operates on similar data in parallel using same few operations.
         HDMI and DP cables can be connected to it to show the visual information on a monitor.
Note that both CPU and GPU have Cache, and GPU also has its own RAM called VRAM (Video RAM).

--- Specifications ---
1. Ethernet Header : Operates on a data link (layer 2). It includes a Destination MAC Address 6 bytes in size, a
   Source MAC Address also 6 bytes in size, Total Length 2 bytes in size, Upper Layer Data from 46 to 1500 bytes in
   size, and a Frame Check Sequence (CRC) 4 bytes in size. Total size is 6 + 6 + 2 + (from 46 to 1500) + 4. A
   Preamble (7 bytes) and a Start Frame Delimiter (1 byte) are always added before the frame header for clock sync.
