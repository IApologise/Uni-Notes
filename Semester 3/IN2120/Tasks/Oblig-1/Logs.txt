Step 9-10: Authenticity Verification
I have successfully verified the authenticity of an RSA, SHA-256 signature, by using a message and a public key. The result can be seen in the "Proof.png". Fun fact: private key since the private key is only known by the sender, it is used to sign the message. Thus, it is the only credible way to verify authenticity.

Here is a more detailed explanation with RSA as an example. We choose {a} and {b} such that {ab ≡ 1}. Our private key will have the {a}, and public key {b}. When creating a signature {S} we do {S = mod_n( H(M)^a )} where {H} is a hash function and {M} is our message and {n} is a common value found in both private and public key. Now, to verify the authenticity we check whether {H(M) ≡ mod_n( H(M)^ab )}. If {ab ≡ 1}, then we get {H(M) ≡ H(M)} and the verification is complete successfully. Note that both private and public key values were used to verify which couldn't have been done otherwise.
