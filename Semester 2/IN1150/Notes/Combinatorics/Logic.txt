Cardinality: |_|
This one takes a set as an input and gives the number of elements
it has as an output result. So basically it is a counter. It can
also count relations in a relation, and do much more than that.

But these other unique abilities are only found in special scenarios.
More on those special scenarios can be found on the section of whatever
the input is. If nothing is found, then there is no special case.



Cartesian Product: _ × _
A function that takes both sets as inputs and creates all the
possible unique combinations between all of their elements.
So in the end a relation is given as a result of such operation.

Because a relation is given the order is important.
For example, if we have two sets A = {1, 2} and B = {2, 3},
then a cartesian product would give the following result:
A × B = {1, 2} × {2, 3} = {<1, 2>, <1, 3>, <2, 2>, <2, 3>},
and not the other way around.



Power Set: P(_)
A function that takes in a set as an input, and
returns all of the possible subsets of that set.

So for example a power set P of a set S where S = {1, 2, 3}
would be P(S) = {Ø, {1}, {2}, {3}, {1, 2}, {1, 3}, {2, 3}, {1, 2, 3}}.
That is because Ø ⊆ S, therefore Ø ∈ P(S).

When asked about the amount of subsets in a set, a cardinality
of a power set is essentially what is asked for, so |P(S)| is
the amount of subsets in a set.

Taking a cardinality of a power set that is countably infinite
results in a set cardinality that is uncountably infinite.

If one may create a function that maps all of the outputs from
the first set to their corresponding outputs in another set,
then both are said to have the same cardinality. Note that the
function must be bijective.

If two infinite sets can be mapped to each other with the help
of a function or other methods, then both have the same cardinality.
The function, therefore, must be bijective.
